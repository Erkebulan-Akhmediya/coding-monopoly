# Coding Monopoly ойынына қош келдіңіз! 🎲

**Coding Monopoly** – бағдарламалық инженерлерге арналған нақты уақыттағы көп ойыншылы үстел ойыны. Кодтау тапсырмаларын шешіңіз, XP жинаңыз, кубиктерді лақтырыңыз және 32 ұяшықты тақтада жүріңіз!

---

### 🎯 Мақсаты
Ойынды жеңу үшін бірінші болып **500 XP** жинаңыз!

---

### 🔄 Кезегіңіз қалай өтеді
1. **Қиындықты таңдаңыз**:
   - 🟢 **Оңай**: 30 секундтық таймер → дұрыс жауап үшін **1 сүйек лақтыру**.
   - 🟡 **Орташа**: 45 секундтық таймер → дұрыс жауап үшін **2 сүйек лақтыру**.
   - 🔴 **Қиын**: 60 секундтық таймер → дұрыс жауап үшін **3 сүйек лақтыру**.
2. **Тапсырманы шешіңіз**:
   - Таймер аяқталмастан бұрын көп таңдаулы немесе мәтін енгізу сұрағына жауап беріңіз.
3. **Сүйек лақтыру және қозғалу**:
   - **Дұрыс**: Сүйек лақтырып, тақтада алға жылжыңыз.
   - **Қате немесе уақыт аяқталды**: 0 лақтыру, кезегіңіз дереу аяқталады.

---

### 🗺️ Тақта және арнайы ұяшықтар
Ойын тақтасында бірегей әсерлері бар **32 шеткі ұяшық** бар:

- 🚩 **Орналастыру (0-ұяшық / GO)**: Тікелей қонсаңыз, **+100 XP**, немесе айналым кезінде өтсеңіз, **+50 XP** аласыз.
- 🧊 **Кодты мұздату (8-ұяшық)**: Тоқтату айыбы — сіз код мұздатуға түсіп, кідіресіз.
- ☕ **Кофе үзілісі (16-ұяшық)**: Демалу аймағы, **+5 XP** береді.
- 🚨 **Deadline (24-ұяшық)**: Жоғары тәуекелді оқиға! 50% ықтималдықпен **+50 XP** немесе 50% ықтималдықпен **-20 XP**.
- 📈 **XP табу / 📉 XP жоғалту**: Ұяшықтың мәніне сәйкес XP қосады немесе азайтады.
- ⚡ **Екі есе XP**: Келесі XP табуыңызды **2 есе** көбейтеді.
- 🎟️ **Тегін өту**: Айыптардан қорғау үшін инвентарьға өту билетін береді.
- 🌀 **Телепортация**: Токеныңызды бірден негізгі ұяшыққа телепортациялайды.
- ⏭️ **Келесіні өткізу**: Келесі кезектегі жүрісіңізді өткізеді.
- 🏆 **Арнайы сынақ**: **+30-дан +35 XP-ге** дейінгі бонустық сынақ сыйлығын береді.
- ❓ **Құпия**: Каталогтан кездейсоқ әсерді іске қосады.
